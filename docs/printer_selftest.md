# Чек-лист первого запуска принтера

> Механика: CoreXY, ось Z инвертирована (Z=0 — стол вверху у сопла,
> Z=position_max≈312 — стол внизу, отведён). Проба типа Voron Tap,
> собственная конструкция. Отдельный концевик парковки Z (PF2) и
> отдельная проба (PF1).

## СТОП-УСЛОВИЯ (сразу рубить питание)

| Этап | Проверка | Опасность |
|------|----------|-----------|
| 1 | Направление Z: «+» = стол ВНИЗ | Стол едет вверх, давит сопло/раму |
| 2 | Хоуминг Z в максимум внизу | Уход в неверную сторону на скорости |
| 4 | Проба Tap: останов при касании | Продавливание сопла в стол |

---

## ЭТАП 0. Предстартовые проверки (без движения и нагрева)

- [ ] `FIRMWARE_RESTART` — стартует без ошибок конфига
- [ ] Проверен `[include features.cfg]` (вернуть или осознанно убрать)
- [ ] sudoers для shell-команд ограничен конкретными строками, не NOPASSWD:ALL
- [ ] `HELP` — все кастомные макросы зарегистрированы
- [ ] `M105` — все термисторы показывают комнатную температуру, нет NaN/-273

## ЭТАП 1. Моторы и направления (КРИТИЧНО, палец на питании)

- [ ] `FORCE_MOVE STEPPER=stepper_x DISTANCE=10 VELOCITY=20` — X вправо
- [ ] `FORCE_MOVE STEPPER=stepper_y DISTANCE=10 VELOCITY=20` — Y назад
- [ ] `FORCE_MOVE STEPPER=stepper_z DISTANCE=5 VELOCITY=5` — стол ВНИЗ от сопла
- [ ] `QUERY_ENDSTOPS` — X/Y/Z-концевик срабатывают при нажатии рукой
- [ ] PF2 (парковка) и PF1 (проба) — разные датчики, независимы

## ЭТАП 2. Хоуминг (по одной оси)

- [ ] `G28 X` → `M114` X≈436
- [ ] `G28 Y` → `M114` Y≈310
- [ ] `G28 Z` — стол ВНИЗ к концевику → `M114` Z≈312
- [ ] `G28` — порядок Z→Y→X без столкновений

## ЭТАП 3. Границы перемещений

- [ ] `G1 X10 Y10` / `G1 X430 Y305` / `G1 X218 Y150` — без стуков в углах
- [ ] `G1 Z50` / `G1 Z300` / `G1 Z10` — стол ходит вниз без упора

## ЭТАП 4. Проба (Tap) и калибровка Z

- [ ] `QUERY_PROBE` — open в покое, TRIGGERED при нажатии
- [ ] `PROBE` в центре — останов при касании, без продавливания
- [ ] `PROBE_ACCURACY` — разброс в пределах samples_tolerance (лучше <0.02)
- [ ] `_PREPARE_PROBE` — срыв магнита, откат 2 мм вниз
- [ ] `_CALIBRATE_Z_HEIGHT` — полный цикл, вменяемый Z в M114

## ЭТАП 5. Датчики филамента

- [ ] `QUERY_FILAMENT_SENSOR SENSOR=0` — detected/not detected
- [ ] switch_sensor 0: вынуть филамент → PAUSE + «Филамент закончился»
- [ ] motion_sensor 0m: остановить движение → «Филамент не движется»

## ЭТАП 6. Вентиляторы и подсветка (без нагрева)

- [ ] `SET_PIN PIN=Extruder_led VALUE=1` — подсветка вкл
- [ ] `TOGGLE_LED` — переключает состояние
- [ ] `M106 S128` — обдув ~50%, `M106 S255` — ~90% (max_power 0.9)
- [ ] `M107` — обдув выкл
- [ ] Вентилятор крышки крутится при движении/нагреве

## ЭТАП 7. Нагреватели и защиты (у огнетушителя)

- [ ] `M104 S150` → wait → `M104 S0` — экструдер греется
- [ ] `M104 S460` — ОТКАЗ (лимит 450)
- [ ] `M140 S60` → wait по "heater_generic heater_bed" → `M140 S0`
- [ ] `M140 S170` (камера холодная) — ОТКАЗ (защита теплового шока)
- [ ] `M141 S50` — камера греется (комбинированный сенсор)
- [ ] `_TURN_OFF` — всё гаснет

## ЭТАП 8. Филамент (сопло горячее)

- [ ] `LOAD_FILAMENT` на холодную — ОТКАЗ (если min_extrude_temp боевой)
- [ ] `M109 S220` + `LOAD_FILAMENT SPEED=300` — подаёт филамент
- [ ] `UNLOAD_FILAMENT` — откатывает

## ЭТАП 9. Pressure Advance

- [ ] `M900 K0.04` — применяется
- [ ] `SET_PRESSURE_ADVANCE ADVANCE=0.05` затем `SET_PRESSURE_ADVANCE` — держит 0.05

## ЭТАП 10. Сетка стола

- [ ] `M190 S60` + `BED_MESH_CALIBRATE` — меш 5×4, профиль "60°C"
- [ ] `LOAD_BED_MESH` — загружает "60°C"
- [ ] `BED_MESH_CALIBRATE ADAPTIVE=1 ADAPTIVE_MARGIN=10` — адаптив

## ЭТАП 11. Пауза / возобновление / отмена

- [ ] `PAUSE` — откат, стол ВНИЗ на 10 мм, голова в угол
- [ ] `RESUME` — возврат филамента, доезд до точки, продолжение
- [ ] `CANCEL_PRINT` — откат, парковка, стол вниз, нагрев off
- [ ] PAUSE на детали 50+ мм — сопло НЕ врезается в напечатанное

## ЭТАП 12. Продувка

- [ ] `_PURGE_LINE MIN_X=50 MIN_Y=50 MAX_X=150 MAX_Y=150` — 3 полоски сбоку
- [ ] `_PURGE_POINT` — клубок за столом, сопло не в раму

## ЭТАП 13. Пробная печать (кубик 20×20)

- [ ] `_START_PRINT` — весь цикл до старта
- [ ] Первый слой ровный (Tap-offset корректен на горячую)
- [ ] `_END_PRINT` — отрыв, парковка, стол вниз, всё off
- [ ] Оценить качество первого слоя (калибровка Z идёт до догрева сопла)

## ЭТАП 14. Периферия

- [ ] `POST_COOLING_CYCLE START=50 END=40 STEP=-2 DPH=600` — пошагово
- [ ] `POST_COOLING_CYCLE START=40 END=50 STEP=-2` — ОШИБКА (знак шага)
- [ ] `_USB_INSTALL` / `_USB_REMOVE` — монтирование
- [ ] `_BACKUP` — архив в config/backups/
- [ ] `PID_CALIBRATE HEATER=extruder TARGET=220` — калибровка + рестарт
- [ ] `PID_CALIBRATE HEATER=xxx` — только ошибка, БЕЗ рестарта
